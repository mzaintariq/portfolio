# Local fonts

Latin variable WOFF2 files served locally through `next/font/local`. Builds and
visitors do not need to contact Google Fonts.

| Family | Axes | Source |
| --- | --- | --- |
| Manrope | Weight 200–800 | https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2 |
| DM Sans | Weight 100–1000; optical size 9–40 | https://fonts.gstatic.com/s/dmsans/v17/rP2Hp2ywxg089UriCZOIHTWEBlw.woff2 |

Retrieved from Google Fonts on 2026-09-21. Both families use the SIL Open Font
License; their copyright notices and full licenses are included alongside the
font files as `Manrope-OFL.txt` and `DM-Sans-OFL.txt`.

These files cover the current English content. Other scripts and unsupported
characters use the system fallback; add appropriate subsets if content expands.
